# Claude Code 完全ガイド

Claude Code を触ったことがない人に向けた、日本語のスライド資料です（全22章と付録、207枚）。

## 見かた

1. `Claude Code 完全ガイド.html` をダウンロードします（ファイルを開き、右上の「Download raw file」ボタン）。
2. ダウンロードしたファイルをブラウザで開きます。

ファイル1つで動きます。フォントは Google Fonts から読み込むため、インターネットにつながった状態で開いてください。
